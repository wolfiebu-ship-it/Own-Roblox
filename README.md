# Klotzwelt

Ein eigenes Blockwelt-Spiel für den Browser, gebaut mit [three.js](https://threejs.org).
Gestalte deine Klotzfigur und spiele einen von zwei Modi:

- **Himmelsparcours**: Springe über schwebende Inseln, balanciere über Lava, fahre auf beweglichen Plattformen mit und steige den Wendelturm hinauf bis ins goldene Ziel. Dabei gibt es Münzen zum Sammeln, Checkpoints, eine Stoppuhr und eine Bestzeit.
- **Baukasten**: Setze und entferne Klötze in 12 Farben. Dein Bau wird im Browser gespeichert.

## Starten

`index.html` im Browser öffnen. Eine Internetverbindung wird für three.js und die Schriften gebraucht.

## Steuerung

| Aktion | Tastatur/Maus | Touch |
| --- | --- | --- |
| Laufen | WASD oder Pfeiltasten | Joystick links |
| Springen | Leertaste | Sprung-Taste |
| Kamera drehen | Maus ziehen, Q/E | Bildschirm ziehen |
| Zoomen | Mausrad | – |
| Klotz setzen | Linksklick | Tippen |
| Klotz entfernen | Rechtsklick oder Shift+Klick | Werkzeug „Abbauen“ + Tippen |
| Farbe wählen | 1–0, ß, ´ | Farbleiste |
| Menü | Esc | Menü-Knopf |
