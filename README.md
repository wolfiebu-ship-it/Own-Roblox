# Klotzwelt

Ein eigenes Blockwelt-Spiel für Browser und iPhone, gebaut mit [three.js](https://threejs.org).

## Was es gibt (Etappe 1)

- **Avatar-Editor**: Name, Körperfarben (Kopf, Torso, Arme, Beine einzeln oder alles auf einmal), Gesicht, Hut, Shirt, Hose und Rücken-Accessoire.
- **Shop**: 39 Sachen in 5 Kategorien (Hüte, Gesichter, Shirts, Hosen, Rücken). Vor dem Kauf kannst du alles anprobieren. Bezahlt wird mit Spielgeld (Münzen), nicht mit echtem Geld.
- **Münzen verdienen**: Im Himmelsparcours bringt jede Münze 5, das Ziel 25. Zum Start gibt es 150 Münzen.
- **Himmelsparcours**: Inselsprünge, Lava, bewegliche Plattformen und Wendelturm, mit Checkpoints, Stoppuhr und Bestzeit.
- **Baukasten**: Klötze in 12 Farben setzen und entfernen. Dein Bau wird gespeichert.
- **Als App auf dem iPhone**: Web-App mit eigenem Symbol und Vollbild, die auch offline läuft.

Profil, Münzen und Bauten werden im Browser auf dem jeweiligen Gerät gespeichert.

## Auf das iPhone bringen

1. Die Seite muss im Internet erreichbar sein, zum Beispiel über **GitHub Pages**: im Repo unter *Settings → Pages* den Branch `master` und den Ordner `/ (root)` wählen. Nach ein bis zwei Minuten läuft die Seite unter `https://<name>.github.io/Own-Roblox/`.
2. Die Adresse auf dem iPhone in **Safari** öffnen.
3. Auf **Teilen** tippen und **Zum Home-Bildschirm** wählen.

Danach startet Klotzwelt wie eine App, im Vollbild und mit eigenem Symbol.

## Steuerung

| Aktion | Tastatur/Maus | Touch |
| --- | --- | --- |
| Laufen | WASD oder Pfeiltasten | Joystick links |
| Springen | Leertaste | Sprung-Taste |
| Kamera drehen | Maus ziehen, Q/E | Bildschirm ziehen |
| Zoomen | Mausrad | – |
| Avatar drehen (Startseite) | Maus ziehen | Wischen |
| Klotz setzen | Linksklick | Tippen |
| Klotz entfernen | Rechtsklick oder Shift+Klick | Werkzeug „Abbauen“ + Tippen |
| Zurück | Esc | Zurück-Knopf |
